# 90-second demo script

One story, no dead air. Rehearse with the dev servers warm.

**Setup (before judges arrive):** `npm run dev` + `npm run marimo:gallery`.
Open the app, pick **Student**, keep the profiler collapsed.

| Time | Do | Say |
|---|---|---|
| 0:00 | Click **Spin — surprise me** | "No setup. The wheel picks real code and builds a lesson from that exact file." |
| 0:05–0:25 | While it generates, point at the journey strip | "This is the Primer idea: it remembers the learner. Skills, misconceptions, story — every lesson compounds." |
| 0:25 | Lesson lands: read the hook aloud | "Same code, but the story and analogy adapt to a 10-year-old gamer." |
| 0:35 | Step the **trace slider** twice | "Animation here means watching state change, not watching a video." |
| 0:50 | Playground: predict, then **Run** | "Predict first, then run — that's the research-backed order." |
| 1:00 | Answer one quiz question **wrong on purpose** | "Wrong answers teach: here's the misconception, and the trace step that disproves it." |
| 1:10 | Point at the journey strip (level moved) | "That answer just updated the learner model. Next lesson will re-check it." |
| 1:20 | Click **Open in Marimo** | "And the same lesson is alive in marimo — sliders, checks, reorder-the-code, in Python." |
| 1:30 | Stop | "Students learn, teachers get mark schemes, parents get ten-minute games. One engine, three doors." |

**If generation stalls >30s:** switch to the Teacher tab and generate a study guide
(same engine, second act) — never stare at a spinner in silence.

**Backup line if asked about scale:** "Generation runs on our own Baseten
deployment, tutor follow-ups on a small model — private-tutor quality without
private-tutor cost."
